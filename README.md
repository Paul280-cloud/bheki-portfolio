# Bheki Buthelezi — Portfolio

Personal portfolio site: bio, the projects I've built (SiteLeads, FixMyKasi), skills, and contact details.

- **Live site:** https://bheki-portfolio.vercel.app <!-- update once deployed -->
- **Capstone project:** [SiteLeads](https://github.com/Paul280-cloud/siteleads) — https://siteleads.vercel.app

## Stack

React 18, Vite 5, TypeScript, Tailwind CSS, Vitest + React Testing Library, deployed on Vercel.

## Run it locally

```bash
npm install
npm run dev
```

## Commands

| Command | What it does |
|---|---|
| `npm run dev` | Local dev server |
| `npm run lint` | ESLint |
| `npm run typecheck` | TypeScript check |
| `npm test` | Runs the test suite |
| `npm run build` | Production build |
| `npm run check` | Runs lint, typecheck, test and build (run before every PR) |
